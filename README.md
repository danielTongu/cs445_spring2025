# CS 445: Data and Information Visualization

Coursework archive from CS 445 at Central Washington University, completed in Spring 2025.

## Topics represented

- Data preparation and exploratory analysis
- Statistical and geographic visualization
- R-based data processing
- Jupyter notebook exercises
- Shapefile and geospatial dataset analysis
- A group project examining credit-card fraud patterns

## Organization

The repository contains labs, quizzes, datasets, and staged project materials created throughout the course. Individual directories preserve the original assignment structure.
